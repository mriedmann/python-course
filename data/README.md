# Course datasets – data card

All data is **artificial**. *Fluvia Process Systems GmbH*, its customers, sales reps and
competitors are fictional; any resemblance to real companies is coincidental.
Generated by `tools/generate_datasets.py` (run from the repository root) (standard library only, seed 2026, reproducible).
Licence: CC0 – free to use, change and publish.

Story: Fluvia sells pumps, heat exchangers, agitators, valves and service packages to process
plants in Central Europe. Learners play an analyst in presales/sales and later look at plant
data from a customer.

| File | Role | Rows | Encoding | Used in units |
| --- | --- | --- | --- | --- |
| `quotes.csv` | **Anchor dataset**: one row per quote line, Jan 2023 – Dec 2025 | 1,073 | UTF-8 | U5–U12 (as a list via setup cell before U8), U15 |
| `products.csv` | Product catalogue with technical specs | 24 | UTF-8 | U6 (dict), U12 (`merge`), U14 (`Pump` datasheet) |
| `customers.csv` | Customer master data | 36 | **Windows-1252** | U8 (encodings), U11, U12 (`merge`) |
| `pump_station_readings.csv` | **Unseen** dataset for the final task: hourly SCADA export, 2 pumps, Q1 2025 | 4,320 | UTF-8 | U16 final task only |
| `api/*.json` | Snapshots of the U13 web APIs (not yet generated, see roadmap phase 3) | – | UTF-8 | U13 fallback |

Common format (like a German Excel export): delimiter `;`, decimal comma, dates `dd.mm.yyyy`.

```python
pd.read_csv("quotes.csv", sep=";", decimal=",")

```

## Columns

**quotes.csv** – `quote_id`, `quote_date`, `customer_id` (→ customers), `product_id` (→ products),
`quantity`, `unit_price_eur` (after discount), `discount_pct`, `status` (Won / Lost / Open),
`decision_date` (empty while open), `sales_rep`, `region` (DACH / South / CEE),
`lead_time_weeks`, `lost_to_competitor` (empty unless lost and known).

**products.csv** – `product_id`, `product_name`, `category`, `flow_m3h`, `head_m`, `power_kw`,
`material`, `list_price_eur`, `launch_date`. Specs are empty where they do not apply (e.g. valves).

**customers.csv** – `customer_id`, `customer_name` (contains ä ö ü ß á Š É ó …), `country`,
`industry`, `segment` (Key account / Standard), `customer_since`.

**pump_station_readings.csv** – `timestamp` (`dd.mm.yyyy HH:MM`), `pump_id` (PU-01 / PU-02),
`flow_m3h`, `discharge_pressure_bar`, `power_kw`, `motor_temp_c`, `state` (RUN / STOP / MAINT).

## Built-in patterns (what analysis should find)

- Win rate ≈ 48 % of decided quotes; higher discount → higher win rate; long lead times → lower.
- Region win rates: CEE ≈ 41 %, DACH ≈ 49 %, South ≈ 51 %.
- Seasonality: August dip, peak in October–November; about +8 % quotes per year.
- Key accounts get ~12 % discount vs ~5 % for standard customers and order larger quantities.
- Final task: pumps alternate weekly as duty pump. **PU-02's specific energy (kWh/m³) rises
  ~7 % from January to March** (0.177 → 0.189 after removing outages, spikes and non-RUN rows), PU-01 stays flat at ~0.173 → recommend inspecting PU-02.

## Deliberate mess (for cleaning exercises – keep it!)

| Issue | Where | Count | Teaches |
| --- | --- | --- | --- |
| Status spelled ` Won`, `won`, `WON`, `Lost `, `lost`, `open` | quotes | 25 | `str.strip().str.capitalize()` |
| Missing `discount_pct` | quotes | 40 | `isna`, `fillna`/`dropna` |
| Unit price typed 10× too high | quotes | 3 | outliers, plotting as a check |
| `quantity` = 0 (placeholder quotes) | quotes | 4 | filtering |
| Exact duplicate rows (exported twice) | quotes | 6 | `duplicated`, `drop_duplicates` |
| Trailing space in `sales_rep` | quotes | 15 | `groupby` surprises, `str.strip` |
| File saved as Windows-1252 | customers | whole file | `encoding=` (UTF-8 read fails) |
| Power meter outage (blank `power_kw`) | readings | 30 h × 2 pumps | missing values in time series |
| Pressure spikes `0,00` / `99,90` | readings | 8 | sensor plausibility filters |
| Maintenance window (state `MAINT`) | readings | 6 h | filtering by state |
